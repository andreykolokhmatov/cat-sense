# Plan: нижняя оранжевая панель с котом и кнопками 2x2 (инфо, смена камеры, человек/кошка, сохранить кадр с репликой) + манифест для запуска с экрана Домой   (slug: bottom-panel)

## TL;DR

Камера занимает верхние ~70% экрана, снизу сплошная оранжевая панель: слева кнопки 2x2 (Инфо, Камера, Человек/Кошка, Сохранить), справа кот "на подоконнике", пузырь над котом заходит на камеру. Режим "Кошка" это честное зрение дихромата: матрица цвета из `logic/` плюс размытие. "Сохранить" собирает кадр с котом и репликой на canvas и отдаёт его в share sheet, запасной путь скачивание. Манифест и meta для запуска с экрана Домой. Порядок: каркас панели → фильтр → сохранение → инфо → манифест → смена камеры (режется первой).

## Acceptance criteria

### Раскладка
- iPhone 17 Safari, портрет: камера сверху ~70% высоты, снизу сплошная оранжевая панель ~30% с учётом safe-area. Поверх камеры кнопок нет.
- Кот сидит справа в панели, пузырь над котом перекрывает нижний край камеры. Пузырь и кот не перехватывают тапы (`pointer-events: none`).
- Тап по камере попадает в точку: debug-кроп (`?debug`) центрирован на тапе, в том числе у нижнего края камеры и после сворачивания тулбара Safari.
- Тап по панели не запускает запрос к коту.
- Интро (`#intro`) работает как раньше. Панель не видна и не фокусируется, пока камера не включена.
- Основной сценарий не изменился: тап по предмету и человеку, запасная фраза при недоступном Gemini. `askCat.js`, `pickPhrase.js`, `api/**`, `phrases.json` не менялись.

### Человек/кошка
- По умолчанию режим "Кошка": красный и зелёный предметы выглядят одним жёлто-оливковым тоном, синий остаётся синим, картинка мягче и чуть менее насыщена.
- Кнопка переключает на "Человек" (без фильтра) и обратно, `aria-pressed` отражает режим.
- Кроп для Gemini всегда без фильтра (`snapshot.js` рисует сырой кадр), в обоих режимах.
- Если SVG-фильтр на iPhone даёт чёрный кадр или заметные подтормаживания, в коде включён запасной CSS-фильтр, видео не ломается.

### Сохранение кадра
- "Сохранить" на iPhone открывает share sheet с JPEG, "Сохранить изображение" кладёт фото в Фото.
- На фото видимая область камеры (как на экране), в режиме "Кошка" с тем же цветовым фильтром, плюс текущая поза кота, текст пузыря и оранжевая полоса с надписью "Кошачье чутьё".
- Пока кот думает (точки), фото сохраняется без пузыря.
- Отмена share sheet ничего не ломает и не показывает ошибку.
- Нет `navigator.share`/`canShare` с файлами: скачивается `cat-sense-<время>.jpg`.
- Сохранение не делает сетевых запросов (вкладка Network).

### Инфо
- "Инфо" открывает `<dialog>`, закрывается кнопкой и тапом по фону.
- Текст: как пользоваться; лицо не покидает телефон, уходит только название эмоции; в вырезке предмета лица закрашены; кошачье зрение (дихромат, размытие); сохранённое фото остаётся на телефоне, лица на нём не закрыты.

### Манифест
- `/manifest.webmanifest` отдаётся, DevTools показывает манифест без ошибок.
- Safari → "На экран Домой": иконка кота на оранжевом фоне, запуск без интерфейса Safari, статус-бар прозрачный, ничего не уезжает под чёлку и home indicator.
- В standalone камера включается, тап, ответ кота и сохранение работают (ручная проверка).

### Смена камеры (если не вырезана)
- "Камера" переключает back/front. Фронтальное видео отзеркалено, тап по левой стороне экрана попадает в левую сторону зеркальной картинки (debug-кроп).
- После переключения тапы игнорируются, пока не прошёл один полный цикл детекции на новом кадре.
- Переключение не удалось: остаётся прежняя камера, кот говорит понятную фразу.
- Устройство с одной камерой: кнопка скрыта или disabled.

### Общее
- `npm test` зелёный, новые тесты проходят.

### Тесты
- `catVision`: строки `CAT_MATRIX` в сумме 1.05; красный и зелёный дают близкое отношение r/g (±10%); синий остаётся с b > r и b > g; клип 0..255; альфа не меняется; `multiply` с единичной матрицей; `toFeColorMatrixValues` даёт 20 чисел, последняя строка `0 0 0 1 0`.
- `wrapText`: короткий текст в одну строку; перенос по словам; длинное слово режется; `maxLines` с `…`; пустая строка → `[]`; эмодзи и кириллица не рвутся (`Array.from`).
- `coverMap`: `visibleSource` для 390x590 и кадра 720x1280 центрирован и в пределах кадра; при совпадающих пропорциях весь кадр; `mirrorPoint(0) = width`; `screenToVideo(mirrorPoint(p))` в зеркальном случае.

## Blockers

Решено 2026-10-30 (человек сказал "запускай билд", приняты рекомендации оркестратора):

1. **Смена камеры вырезана.** Шаг 8 не делаем; `camera.js`, `detect.js`, `mirrorPoint`, `is-mirrored` и критерии раздела "Смена камеры" вне объёма. Кнопки 2x2 без неё: Инфо, Кошка/Человек, Сохранить и одна свободная ячейка (исполнитель предлагает, что туда, или делает сетку 3 кнопки; не придумывать новую функциональность).
2. **Сохранённое фото без закраски лиц.** Принято, в окне "Инфо" об этом сказано.
3. **Один цвет:** `#FA9A3C` (рыжий кота) для панели, интро-кнопки и `theme_color`.
4. **`.memory-bank` и README** обновляет оркестратор после билда (шаг 9 не у исполнителя).

Проверить руками, не решение:
- SVG-фильтр на `<video>` в iOS Safari может давать чёрный кадр или тормозить рядом с двумя моделями (шаг 2a, есть запасной CSS).
- Синхронная сборка кадра 1080 px с циклом по пикселям: фриз 100–300 мс на iPhone, при необходимости ширина 900.
- Standalone на iOS: разрешение камеры может спрашиваться при каждом запуске, скачивание как запасной путь может не работать.
- Генерация PNG из webp через ImageMagick: проверить, что `convert` есть и читает webp.

## Out of scope

- Сборка, сервис-воркер, офлайн-режим PWA.
- WebGL-рендер видео для фильтра.
- Маскировка лиц на сохранённом фото.
- Запись видео и GIF.
- Отдельная раскладка для ландшафта и планшета.
- Реплики кота в зависимости от режима, изменения в `api/`, `askCat`, `pickPhrase`, `phrases.json`.
- Fullscreen API (на iPhone не работает, вместо него standalone).
- Звуки.

## Assumptions

- Режим по умолчанию "Кошка" (Memory Bank: "видит мир через кошачий фильтр"), "Человек" = без фильтра.
- Кошачье зрение = симуляция дейтеранопии Machado 2009 (severity 1) в sRGB на обоих путях. Матрица рассчитана для linear RGB, здесь приближение. Поверх насыщенность 0.8, яркость 1.05, размытие около 1 CSS px. Точной научной модели кошки нет.
- Сохранённое фото как на экране: с фронтальной камеры отзеркалено. Кроп для Gemini всегда из сырого кадра.
- Фото 1080 px по ширине, внизу оранжевая полоса без кнопок.
- Иконки из `curious.webp`, отдельный дизайн иконки не нужен.
- Подписи кнопок: "Как это", "Камера", "Кошка"/"Человек", "Сохранить", иконки эмодзи или inline SVG.
- Все `public/**` у frontend-агента.
