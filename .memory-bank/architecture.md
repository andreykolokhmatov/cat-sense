# Архитектура

## Схема

```
Телефон (браузер)                              Vercel (serverless-функция)
  камера + кошачий фильтр
  COCO-SSD: только люди (приватность)
  Face Landmarker: эмоции
  тап по объекту
    |-- кот "думает" (заглушка)
    `-- POST /api/ask  ------------------------>  проверка, лимиты, ключ
                                                    |
                                                  Gemini API
                                                    |
        реплика кота из ответа модели  <---------- ответ
        (ошибка или таймаут: фраза из phrases.json)
```

## Структура папок

```
api/                 serverless-функции Vercel (Node, ESM)
  ping.js            проверка: функции работают, регион, задан ли ключ
  ask.js             /api/ask: промпт кота, проверка входа, лимиты, таймаут 8 с (телефон ждёт 9.5 с)
  _logo.js           эталон лого "Арены героев" (JPEG base64), уходит в Gemini рядом с вырезкой; `_` = не функция
public/              статика, отдаётся как есть, без сборки
  index.html         экран: камера сверху, оранжевая панель с кнопками и котом снизу
  manifest.webmanifest  запуск с экрана Домой (standalone)
  phrases.json       запасные реплики на случай ошибки модели
  assets/            кот, иконки приложения
  js/
    logic/           чистая логика без DOM, покрыта тестами
    saveFrame.js     сборка кадра с котом и репликой, share sheet
    catView.js       кошачье зрение на живом видео (WebGL)
    marks.js         метки 😾 над обиженными людьми на #overlay
    ...              камера, детекция, кот
test/                тесты логики и функций (node --test)
package.json
```

Vercel сам отдаёт `public/` как сайт и превращает файлы из `api/` в адреса `/api/<имя>`. Сборки нет.

## Контракт `/api/ask`

Запрос:

```json
{ "kind": "object", "label": "cup", "image": "<jpeg base64, вырезка вокруг тапа>" }
{ "kind": "person", "emotion": "happy" }
{ "kind": "person", "emotion": "happy", "torso": "<jpeg base64, одежда, лица закрашены>" }
{ "kind": "person", "emotion": "angry", "grudge": "start" }
```

Любой запрос может нести `"hero": true` (только литерал `true`, иначе поля нет): кот сейчас в маске, реплика в супергеройском стиле.

Ответ:

```json
{ "text": "Это что, пульт? Дай понюхать.", "mood": "curious", "sure": "low", "seen": "пульт" }
{ "text": "Маска надета. Арена героев, я с вами!", "mood": "happy", "sure": "high", "hero": true }
{ "text": "Хочу воды!", "mood": "want" }
```

- object: `{ text, mood, sure, seen?, hero? }`; person с `torso`: `{ text, mood, sure, hero? }`; просто person и обида: `{ text, mood }`.
- `sure`: `high` | `low`. При `low` реплика звучит как догадка или вопрос.
- `seen` (до 60 символов): что увидел Gemini, только для dev-лога, посетителю не показывается.
- `hero` есть только как `true` (Gemini узнал лого и уверен), тогда `text` всегда фиксированная фраза, `mood` = `happy`. Ошибка или таймаут: запасная фраза, `hero` нет никогда.
- `torso`: сырой base64 JPEG без `data:`, до 400 000 символов, невалидный без `grudge` даёт 400. С `grudge` сервер молча его отбрасывает, но фронт его с обидой не шлёт вообще.

Значения `mood`: `want`, `curious`, `scared`, `happy`. Значения `emotion`: `happy`, `surprised`, `angry`, `neutral`. Фронт всегда шлёт `label: "unknown"`: предмет по вырезке определяет Gemini. API ещё принимает имена классов COCO-SSD (`cup`, `cell phone`).

Реплику пишет модель, фронт её только показывает. Ошибка или таймаут: фронт вызывает `pickPhrase` из `public/js/logic/pickPhrase.js`, берёт фразу из `phrases.json` в том же формате `{ text, mood }`, и пользователь видит работающего кота.

## Границы

- Детекция и эмоции идут только на телефоне, сервер видео не получает.
- На сервер уходит вырезка кадра при тапе по предмету и вырезка одежды при тапе по телу человека (не по лицу), если её пропустил локальный гейт лого (`logic/logoGate.js`). На обеих лица закрашены непрозрачно на том же замороженном кадре. При тапе по лицу и при обиде уходит только название эмоции (и `grudge`).
- Ключ Gemini лежит в переменной окружения `GEMINI_API_KEY` на Vercel и в локальном `.env`. В браузер и git не попадает.
- Функция ограничивает размер запроса и частоту обращений, иначе посетители сожгут лимит.
- Лимит выполнения функции на бесплатном тарифе около 10 секунд, поэтому таймаут вызова модели ставим жёстко и короче.
- Камере нужен HTTPS. Vercel даёт его сразу, исключение локально только `localhost`.

`label` проверяется по списку классов COCO-SSD плюс `unknown`, `emotion` по списку эмоций, иначе 400. Ошибки: 405, 400, 429 (лимит), 500 (нет ключа), 502 (ошибка или мусор от модели), 504 (таймаут). На любую из них фронт говорит запасную фразу. Модель по умолчанию `gemini-3.5-flash-lite`: `gemini-3.8-flash` не укладывается в таймаут, `gemini-2.5-flash` закрыт для новых ключей. Модель меняется переменной `GEMINI_MODEL` без правки кода. Системный промпт кота лежит в `SYSTEM_PROMPT` в `api/ask.js`.

`grudge` необязателен и бывает только у `person`: `start` (удержание, кот только что обиделся) или `again` (тап по тому, на кого кот обижен). Другое значение даёт 400, у `object` поле отбрасывается. Без сети фронт берёт фразы из `phrases.grudge.start` / `phrases.grudge.again`.
