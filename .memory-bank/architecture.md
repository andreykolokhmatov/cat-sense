# Архитектура

## Схема

```
Телефон (браузер)                              Сервер Node.js (Timeweb)
  камера + кошачий фильтр
  COCO-SSD: предметы и люди
  Face Landmarker: эмоции
  тап по объекту
    |-- сразу: фраза из phrases.json
    `-- POST /api/ask  ------------------------>  проверка, лимиты, ключ
                                                    |
        живая фраза заменяет запасную  <-------- ответ LLM
```

## Структура папок (план)

```
server/              Node-сервер: отдаёт public/, держит /api/ask
public/
  index.html
  phrases.json       запасные реплики
  assets/            кот, звуки
  js/
    logic/           чистая логика без DOM, покрыта тестами
    ...              камера, детекция, рисование, кот
test/                тесты логики и сервера (node --test)
```

## Контракт `/api/ask` (черновик)

Запрос:

```json
{ "kind": "object", "label": "cup", "image": "<jpeg base64, вырезка вокруг тапа>" }
{ "kind": "person", "emotion": "happy" }
```

Ответ:

```json
{ "text": "Хочу воды!", "mood": "want" }
```

Ошибка или таймаут: фронт оставляет фразу из `phrases.json`. Пользователь ничего не замечает.

## Границы

- Детекция и эмоции идут только на телефоне, сервер видео не получает.
- На сервер уходит кадр только при тапе по предмету.
- Ключ LLM хранится в переменной окружения сервера. Сервер ограничивает размер запроса и частоту обращений, иначе посетители сожгут лимит.
- Камере нужен HTTPS. Исключение только `localhost`.
