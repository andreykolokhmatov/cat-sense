# Решения

- **Идея: кот комментирует мир.** Заменили вариант с глушением голоса: на шумном стенде микрофон работает случайно, а камере шум не мешает.
- **Реплики пишет нейросеть (Gemini), JSON только запасной.** Ответ модели всегда главный. Если API не ответил за таймаут, кот говорит фразу из `phrases.json`, чтобы демо не ломалось из-за интернета и лимитов.
- **Детекция на телефоне, LLM только по тапу.** Рамки нужны мгновенно, а запрос на каждый кадр слишком дорогой и медленный.
- **Эмоции определяем локально.** Blendshapes + простые правила, 3-4 надёжные эмоции: радость, удивление, злость, нейтрально. В LLM уходит только название эмоции, а не лицо. Лица посетителей не отправляем стороннему API (исключение для одежды ниже, лица на ней закрашены).
- **Хостинг Vercel.** Статика из `public/` и serverless-функции из `api/` на одном домене, HTTPS сразу, деплой по пушу. Функции работают в США, что снимает риск блокировки Gemini по региону России. GitHub Pages не подходит: на статике негде держать ключ. Timeweb запасной вариант.
- **LLM: Gemini, с картинкой.** Модель видит вырезку кадра и узнаёт любой предмет, а не только 80 классов COCO.
- **Рамок нет, предметы называет только Gemini.** COCO-SSD путал предметы (книга становилась холодильником, шкаф телевизором). Предмет теперь просто вырезка вокруг тапа. COCO-SSD остался только для людей: закрашивает голову, если Face Landmarker не нашёл лицо, и превращает тап по телу в тап по человеку, чтобы фото не ушло в Gemini.
- **Статуэтки не люди.** Тело без лица считается человеком только при COCO score >= 0.75 (`PERSON_MIN_SCORE` в `pickTarget.js`), иначе это предмет и вырезка уходит в Gemini с закрашенными головами всех тел. Компромисс принят: слабо видимый человек без найденного лица может уйти вырезкой тела с закрашенной головой.
- **Обида по удержанию** (тема "заткнуть человека"). Удержание 600 мс на человеке: злой кот сидит у него на голове, обиженные реплики (`grudge: 'start' | 'again'` в `/api/ask`). С 31.10 (вечер) кот помнит обидчика 2 минуты после ухода из кадра и узнаёт его по виду: цвета волос и одежды плюс пропорции лица (`logic/appearance.js`, `logic/grudges.js`). Считается только на телефоне, в памяти страницы, ничего не хранится и не отправляется. Трекер по-прежнему ведёт лица по положению, но обида каждый цикл сверяется с видом, поэтому не перескакивает на другого человека при повороте камеры. Вернулся: метка снова на нём, кот сам говорит фразу из `phrases.grudge.back`. Повторное удержание на обидчике: мир, фраза из `phrases.grudge.peace`. Обе фразы локальные, без Gemini. Риск принят: двух людей в одинаковой одежде с похожими лицами кот может спутать.
- **Реплика в панели.** Пузырь внутри оранжевой панели, над камерой ничего; длинный текст уменьшает шрифт до 12px и обрезается "…". На сохранённом фото пузырь по-прежнему поверх камеры.
- **Тап по человеку.** Тап по телу ведёт к лицу этого человека. Уверенное тело без лица (score >= 0.75) остаётся `person` и уходит с эмоцией `neutral`, чтобы его изображение не попало к Gemini.
- **Лого "Арены героев" (31.10, D1 = b).** Тап по телу человека (не по лицу и не при обиде) вырезает квадрат одежды вокруг тапа (`torsoBox` в `pickTarget.js`, 0.6 ширины тела). Сначала локальный гейт `logic/logoGate.js` на 32×32 (футболки чёрные, лого белая или бледно-голубая маска: белого 3–45%, тёмного ≥ 30%). Не прошёл: вырезка не уходит, только эмоция. Прошёл: лица закрашиваются и `torso` уходит в Gemini. Это меняет прежнее "фото посетителей не отправляем": одежда уходит, лица нет. В окне "Как это" сказано честно.
- **Эталон лого едет с сервера** (`api/_logo.js`) рядом с каждой вырезкой: модель сравнивает с картинкой, а не со словесным описанием. Лого узнаётся только через Gemini, офлайн нет. `hero` ставит сервер при `logo && sure=high`, текст фиксированный (D2): "Маска надета. Арена героев, я с вами!".
- **Маска держится 3 ответа или 30 с** (`HERO_TAPS`, `HERO_MS` в `logic/heroMask.js`), что раньше; новый hero перезапускает оба. Пока маска надета, каждый запрос идёт с `hero: true` (флаг берётся до счёта текущего тапа), и реплики в супергеройском стиле.
- **Без сборки и фреймворка.** Один экран, чистые ES-модули, деплой без шага сборки.
- **Экран: камера сверху ~70%, оранжевая панель снизу.** Кнопки не закрывают камеру. Кнопки: "Как это", "Кошка/Человек", "Сохранить". Смену камеры вырезали: риск для приватности при переключении и мало пользы для демо. Цвет бренда `#FA9A3C`, рыжий кота.
- **Кошачье зрение = дихромат.** Матрица дейтеранопии Machado 2009 плюс насыщенность 0.7, яркость 1.05, размытие и виньетка (`logic/catVision.js`). Живое видео рисуется через WebGL-шейдер на canvas поверх video (матрица, размытие, виньетка): WebKit на iPhone игнорирует SVG-фильтр на `<video>`. Без WebGL запасной CSS-фильтр, его же можно включить `?catcss`. Вырезка для Gemini всегда без фильтра. Это приближение, точной научной модели кошки нет.
- **Сохранённое фото локальное и без закраски лиц.** Кадр собирается на canvas и уходит в share sheet, в сеть ничего не отправляется. В окне "Как это" сказано, что фото остаётся только у пользователя. Модель там называется просто "нейросеть".
- **Запуск с экрана Домой вместо полноэкранного режима.** На iPhone Safari не даёт странице полноэкранный режим, поэтому манифест с `display: standalone`.
- **Звук вторичен.** Весь смысл реплик виден текстом, в шуме звук могут не услышать.
- **Отказались:** вырезание голоса человека, летающий нос как игра, обучение своих моделей.
- **Харнес облегчён.** Убраны design-цикл, skeptic и агенты других стеков. Тест-гейт только на логике и переписан на Node, чтобы работать без `jq`.
