# Решения

- **Идея: кот комментирует мир.** Заменили вариант с глушением голоса: на шумном стенде микрофон работает случайно, а камере шум не мешает.
- **Реплики пишет нейросеть (Gemini), JSON только запасной.** Ответ модели всегда главный. Если API не ответил за таймаут, кот говорит фразу из `phrases.json`, чтобы демо не ломалось из-за интернета и лимитов.
- **Детекция на телефоне, LLM только по тапу.** Рамки нужны мгновенно, а запрос на каждый кадр слишком дорогой и медленный.
- **Эмоции определяем локально.** Blendshapes + простые правила, 3-4 надёжные эмоции: радость, удивление, злость, нейтрально. В LLM уходит только название эмоции, а не лицо. Фото посетителей не отправляем стороннему API.
- **Хостинг Vercel.** Статика из `public/` и serverless-функции из `api/` на одном домене, HTTPS сразу, деплой по пушу. Функции работают в США, что снимает риск блокировки Gemini по региону России. GitHub Pages не подходит: на статике негде держать ключ. Timeweb запасной вариант.
- **LLM: Gemini, с картинкой.** Модель видит вырезку кадра и узнаёт любой предмет, а не только 80 классов COCO.
- **Рамок нет, предметы называет только Gemini.** COCO-SSD путал предметы (книга становилась холодильником, шкаф телевизором). Предмет теперь просто вырезка вокруг тапа. COCO-SSD остался только для людей: закрашивает голову, если Face Landmarker не нашёл лицо, и превращает тап по телу в тап по человеку, чтобы фото не ушло в Gemini.
- **Тап по человеку.** Тап по телу ведёт к лицу этого человека. Человек без лица всё равно остаётся `person` и уходит с эмоцией `neutral`, чтобы его изображение не попало к Gemini.
- **Без сборки и фреймворка.** Один экран, чистые ES-модули, деплой без шага сборки.
- **Экран: камера сверху ~70%, оранжевая панель снизу.** Кнопки не закрывают камеру. Кнопки: "Как это", "Кошка/Человек", "Сохранить". Смену камеры вырезали: риск для приватности при переключении и мало пользы для демо. Цвет бренда `#FA9A3C`, рыжий кота.
- **Кошачье зрение = дихромат.** Матрица дейтеранопии Machado 2009 плюс насыщенность 0.7, яркость 1.05, размытие и виньетка (`logic/catVision.js`). Живое видео рисуется через WebGL-шейдер на canvas поверх video (матрица, размытие, виньетка): WebKit на iPhone игнорирует SVG-фильтр на `<video>`. Без WebGL запасной CSS-фильтр, его же можно включить `?catcss`. Вырезка для Gemini всегда без фильтра. Это приближение, точной научной модели кошки нет.
- **Сохранённое фото локальное и без закраски лиц.** Кадр собирается на canvas и уходит в share sheet, в сеть ничего не отправляется. В окне "Как это" сказано, что фото остаётся только у пользователя. Модель там называется просто "нейросеть".
- **Запуск с экрана Домой вместо полноэкранного режима.** На iPhone Safari не даёт странице полноэкранный режим, поэтому манифест с `display: standalone`.
- **Звук вторичен.** Весь смысл реплик виден текстом, в шуме звук могут не услышать.
- **Отказались:** вырезание голоса человека, летающий нос как игра, обучение своих моделей.
- **Харнес облегчён.** Убраны design-цикл, skeptic и агенты других стеков. Тест-гейт только на логике и переписан на Node, чтобы работать без `jq`.
