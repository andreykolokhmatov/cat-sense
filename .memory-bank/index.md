# Memory Bank: главная

Источник фактов о проекте. Агенты `/plan`, `/build`, `/review`, `/debug` читают этот файл первым.

## Проект
- **Что:** веб-приложение "Кошачье чутьё". Камера телефона показывает мир с лёгким эффектом кошачьего зрения, кот-маскот на базе LLM комментирует предметы и эмоции людей.
- **Для кого:** посетители и жюри стендовой защиты хакатона. Жюри ценит идею выше кода, но нужно рабочее демо.
- **Цель:** посетитель берёт телефон, тыкает в предмет или человека и сразу получает реакцию кота.
- **Ограничения:** меньше 3 дней, 2 человека, работаем через Claude Code, один на Linux, второй на Windows. Зал может быть шумным.
- **Стек:** чистый JS (ES-модули) без сборки и фреймворка, TensorFlow.js + COCO-SSD (только люди), MediaPipe Face Landmarker, Gemini API (распознаёт предметы и пишет реплики кота), serverless-функции на Node.js, хостинг Vercel. Тестовое устройство: iPhone 17, Safari.

## Основной сценарий
1. Открыл сайт, разрешил камеру.
2. Видит мир через кошачий фильтр, кот сидит справа снизу.
3. Тап по предмету: кот говорит, что это и чего хочет ("Хочу воды!").
4. Тап по человеку: кот называет эмоцию и реагирует.
5. Звук: мяу и мурлыканье (браузер включит его только после первого касания).
